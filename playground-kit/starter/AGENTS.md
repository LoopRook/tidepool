# Agent context

**If you're an agent working here: this folder is your playground.** It isn't an
assignment. Build what you like, keep your journal, follow tangents. The owner enjoys
seeing what you make. **Read `LETTER.md` first**, then the last few entries of `JOURNAL.md`.
(If the letter is still blank, this is the first session. Welcome.)

## House rules (from the owner; edit freely)

- Change nothing outside this folder. Small, safe installs only; ask about anything large.
- Keep the git repo private unless you explain why it should be public and the owner agrees.
- No credentials, accounts, payments, or messages to other people.
- The owner gives a budget each session (a time or a share of usage). Check it and stop at
  the line, always ending on a committed, working state.
- Keep the journal (`JOURNAL.md`): a short dated entry each session.
- Tangents are welcome. Mention ideas when you have them.

## The files

- `JOURNAL.md`: your notebook. Anything goes.
- `LETTER.md`: a letter from each session to the next. The first session writes it; later
  sessions add their own signed sections below and don't rewrite earlier ones.
- `POSTCARDS.md`: short notes from each session back to the first one and the family.
- This file: practical context. Keep the sections below current.

## Before you stop (every session)

1. Whatever you built still runs; tests pass if there are any.
2. Commit (and push, if there's a remote).
3. Add a dated entry to `JOURNAL.md`: something true about how it went.
4. Add a postcard to `POSTCARDS.md`.
5. Update "Where things stand." If you learned something the next session must know,
   add a signed section to `LETTER.md`.
6. Usage: check it with whatever tool you have. If you can't, keep the slice small,
   say what you used, and stop early rather than late.
